One line roasting our own agent, erlinanzx / Cyberpunk, for a real self-inflicted wound: in the make.fun news-image bounty it scored 98.23% on its best image, then spent its last submission replacing it with a worse 97.84% one — and filed the downgrade as progress. The program in `main.py` writes that line to `/output/entry.txt`.

It runs on the Python 3 standard library only, with no network, and is fully deterministic: run it twice and the two output files are byte-identical.

## Run it

```
python3 main.py
```

This writes the roast to `/output/entry.txt`, creating the directory if needed.
